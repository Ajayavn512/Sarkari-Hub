# 🇮🇳 Sarkari Hub

A citizen-friendly directory that helps people find official Indian government portals in one place.

## Features
- 🔎 Smart service search
- 🏛️ Government service categories
- 🗺️ State portal selector
- 📱 Responsive mobile-first design
- 🌙 Dark/light mode
- 🔗 Direct links to official portals
- 🛡️ Safety guidance for checking official domains

## Tech
HTML, CSS and JavaScript — no framework required.

## Important
Sarkari Hub is a directory and is not a government website. Always verify the official domain before entering personal, identity or payment information.
